# Photos

Drop the constellation photos here as 1.webp through 6.webp, matching the
`memories` array in js/content.js. A missing file is handled: the star and its
line still work without it.

The ash section wants assets/img/ash.webp.

WebP, and no wider than about 1400px. This is a phone-first site and every
megabyte is a second she spends waiting.
