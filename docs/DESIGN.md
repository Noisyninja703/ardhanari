# Design

Everything derives from `css/tokens.css`. Change it there, not at the point of
use.

## Colour — six values, resist a seventh

| Token | Hex | Use |
| --- | --- | --- |
| `--void` | `#0A0612` | Page ground; near-black with a violet bias |
| `--ash` | `#8C8794` | Shiva's half; smoke, particles, secondary text |
| `--moon` | `#EFE9DC` | Body text; bone-white, **never** pure `#fff` |
| `--datura` | `#A98CE0` | Cool glow, mist, night-flower accent |
| `--gold` | `#C9A24B` | Parvati's half; seam flare, unlocked states |
| `--kumkum` | `#C1332B` | Reserved. Bindi, wax seals, the third eye. Six uses on the whole site. |

Alphas are named by intent (`--moon-dim`, `--ash-veil`) so usage stays honest.

## Type — three roles

- **Display: Tiro Devanagari Sanskrit.** Chosen because it's a real Sanskrit
  typesetting face with a matched Latin companion, so the shlokas and the
  English headings are the *same* voice rather than two fonts pasted together.
- **Body: Spectral**, italic-forward, `34ch` measure, `1.75` leading. Poetry
  wants air.
- **Utility: Jost**, uppercase, `0.24em` tracking, 11px fixed — tithi labels,
  hints, timestamps. Utility text does not scale.

One fluid scale via `clamp()`, authored at 390px. Mobile and desktop share the
ratio; there is no separate mobile scale.

## Layout — one portrait column, five bands

**No breakpoints. No orientation branches.** The only `@media` rules in the
project are `prefers-reduced-motion` and `hover: none`, both accessibility.

Width is one token:

```css
--column: min(92vw, 34rem);
```

Full width on a phone; a tall centred column on a monitor rather than spreading
out. That's what preserves the pacing of the vertical scroll — a poem that goes
wide stops reading as a poem. **To change how wide the site feels, change that
one value.**

Every section is exactly `100dvh`, divided into proportional bands:

```
┌──────────────────────────────┐
│  10%   tithi label           │
│  15%   heading               │
│  50%   poem / puzzle         │
│  10%   prompt (hint / skip / │
│        "keep going")         │
│  15%   Devanagari footer     │
└──────────────────────────────┘
   + --chrome-h reserved below for the fixed moons
```

Percentages of the device's own height, so a segment fits any screen without
tuning. Hint, skip and the onward cue share one band because none of them is
ever wanted at the same moment as another.

Puzzles build into the **50% band** (`body`), never into the section itself.

## Paint order — load-bearing

Documented in `css/tokens.css`. Check it before inventing a `z-index`.

| z | Layer |
| --- | --- |
| 0 | mist, seam, pointer glow — the backdrop |
| 1 | `.exposure` — darkens the backdrop as she progresses |
| 3 | particles — above the darkening, so stars stay crisp |
| 10 | content — the poem is above all atmosphere |
| 60 | grain |
| 70 | chrome (moons, sound toggle) |

Sections must **not** be `isolation: isolate`, or their content gets trapped
below the fixed overlays.

## Effects, and why each earns its place

- **Grain** — one tiling SVG-noise overlay at 4%, generated by `feTurbulence`
  so there's no image request. This single detail is what stops the page
  reading as a stack of CSS gradients.
- **The seam** — a vertical hairline with ash-tinted left and gold-tinted right.
  Invisible in the void, appears after it, turns gold and softens once the
  halves are rejoined. It's the spine of the whole site.
- **Mist** — stacked radial gradients on 74–92s keyframes, masked to fade
  before each section's top and bottom edge. That mask is what removed the harsh
  seam between segments.
- **Exposure** — a vignette whose opacity is the fraction of puzzles solved, so
  the poem becomes the only lit thing on screen by the end.
- **Text haze** — layered `text-shadow`, not blur. Depth without illegibility.
- **Sweep reveal** — a 300%-wide mask travelling left to right over 1s. Used
  for headings, tithi labels and the Devanagari footer. It must land on the
  opaque third or the text stays permanently dimmed.
- **Particles** — one shared canvas, per-section presets (`stars`, `ash`,
  `embers`), cross-faded as layers. Count scales to viewport area and core
  count with a floor, because a phone thermal-throttling mid-poem is worse than
  fewer motes.
- **Glass** — `backdrop-filter` as an upgrade inside `@supports`; the flat
  translucent fallback looks fine on its own.

## Motion

Slow. `--d-bloom` is 2.6s for verse reveals. Nothing on this page should feel
snappy except the puzzles, which must feel immediate under the finger.

`prefers-reduced-motion` turns off parallax, drift and animation, reveals every
verse without a puzzle, and gives a **static** starfield — respecting the
preference shouldn't mean deleting the atmosphere.

## Accessibility floor

Not optional, and not separate from the design:

- Every puzzle is keyboard-operable with visible focus rings.
- Hit targets ≥44px.
- Hint at 3s, an explicit way past at 15s. **She can never get stuck.**
- Decorative Sanskrit is `aria-hidden` — a screen reader shouldn't try to
  pronounce ornament.
- No hover-only information.
- `noindex`: this is a present, not a portfolio piece.
